# @aayurt/8848-ui-hooks

Utility React hooks for **8848 UI**: `useMediaQuery`, `usePrefersReducedMotion`, `useId`, `useControllableState`, `useEventListener`.

```sh
pnpm add @aayurt/8848-ui-hooks
```

```tsx
import { useMediaQuery } from "@aayurt/8848-ui-hooks";
import { useMediaQuery } from "@aayurt/8848-ui-hooks/use-media-query";
```
