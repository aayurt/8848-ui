# @aayurt/8848-ui-react

React 19 component library for **8848 UI** — minimal, precise, Himalayan-inspired. Accessible Radix primitives styled with Tailwind CSS v4.

```sh
pnpm add @aayurt/8848-ui-react @aayurt/8848-ui-core
```

```css
@import "@aayurt/8848-ui-core/theme.css";
```

```tsx
import { Button } from "@aayurt/8848-ui-react";
import { Input } from "@aayurt/8848-ui-react/input";

<Button variant="default">Begin Ascent</Button>;
```

40+ components: primitives, overlays, sortable Table, RHF + Zod Form, and agentic patterns (ExecutionCard, ToolCallInspector, ApprovalPrompt…). Tree-shakeable subpath exports per component.

Full docs, live registry, and source: https://github.com/aayurt/8848-ui
