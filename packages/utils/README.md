# @aayurt/8848-ui-utils

Shared utilities for **8848 UI**: `cn` (clsx + tailwind-merge), shared `cva` primitives, accessible focus-ring and visually-hidden helpers.

```sh
pnpm add @aayurt/8848-ui-utils
```

```ts
import { cn } from "@aayurt/8848-ui-utils";
import { cn } from "@aayurt/8848-ui-utils/cn";
```

Full docs and source: https://github.com/aayurt/8848-ui
