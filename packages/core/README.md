# @aayurt/8848-ui-core

Design tokens for **8848 UI**: OKLCH mountain palette (Alpine, Sunrise, Slate, Forest, Earth), Tailwind CSS v4 theme, semantic light/dark colors, radii, elevation shadows, and meter-based spacing.

```sh
pnpm add @aayurt/8848-ui-core
```

```css
@import "@aayurt/8848-ui-core/theme.css";
```

Subpaths: `./colors`, `./theme`, `./theme.css`, `./tailwind`.

Full docs and source: https://github.com/aayurt/8848-ui
